# Living Art | Landing page

Site de alta conversão da Living Art, laboratório odontológico digital (Paulistana-PI), para captar dentistas (B2B).

Site estático, sem build: `index.html`, `style.css`, `script.js` e `assets/`.

## Rodar localmente

```bash
python -m http.server 5173
```

Abra http://localhost:5173.
